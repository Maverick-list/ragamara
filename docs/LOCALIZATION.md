## 2. Indonesian Regional Languages Registry
Progressive support architecture covering: Acehnese, Batak (Toba/Karo), Minangkabau, Sundanese, Javanese, Balinese, Sasak, Buginese, Makassarese, Madurese, Banjar, Dayak languages, Gorontalo, Minahasan languages, Ambonese Malay, and Papuan regional languages. Regional entries preserve native terms, distinguish dialects, and mark community/machine-assisted translations transparently.
